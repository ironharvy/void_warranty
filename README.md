# void_warranty

Pre-production materials for a 3D Unity action game inspired by Return Fire and set in a corporate dystopian sci-fi world.

## Current Direction

- Engine: Unity
- Camera: High-angle tactical camera inspired by Return Fire
- Structure: Scripted boarding setup, player controls deployable vehicles inside ships
- Scope: Solo-developed vertical slice first

## Repo Contents

- `world_bible.md`: story, world, characters, and ending structure
- `docs/game-pillars.md`: design principles and non-goals
- `docs/one-page-gdd.md`: compact game definition
- `docs/vertical-slice.md`: first playable slice and scope boundaries
- `docs/vehicle-design.md`: initial vehicle roster and roles
- `docs/ai-pipeline.md`: practical AI-assisted production guidance
- `tasks/roadmap.md`: milestone plan and immediate next tasks

## Collaboration

- `CONTRIBUTING.md`: git workflow, branch rules, and merge expectations
- `AGENTS.md`: operating rules for AI agents and humans
- `tasks/TEMPLATE.md`: template for task-scoped work items
